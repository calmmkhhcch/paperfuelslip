📐 計算公式說明 (由上至下)

  • 1. METERED FUEL ADDED (US GAL) : 輸入「加完油拿到的油單資料 (Liters)」 → 公式 = 公升數 × 0.26417 → 四捨五入取整數，單位 US GAL。
  • 2. 剩餘油量總和 (TOTAL REMAINING) : 油箱1 + 油箱2 + CTR 剩餘油量 (LBS) 自動加總。
  • 3. 加油後油量總和 (TOTAL POST SERVICE) : 油箱1 + 油箱2 + CTR 加油後油量 (LBS) 自動加總，同時此數值即為「FINAL FUEL (LBS)」。
  • 4. *CALCULATED FUEL : 公式 = 剩餘油量總和 + ( 密度 LBS/GAL × METERED FUEL ADDED US GAL )，計算後四捨五入。
  • 5. DIFFERENCE : 公式 = CALCULATED FUEL - 加油後油量總和 (TOTAL POST SERVICE)。根據差值範圍自動標色（綠/橘/紅）。
  • 6. 中油油單密度 ➜ DENSITY 自動換算 : 若輸入「中油油單密度 (KG/LITER)」 → 乘以 8.345 → 自動填入左側 DENSITY (LBS/GAL) 並觸發所有計算。 (例如 0.783 × 8.345 = 6.53) 。若直接修改 DENSITY 亦可，兩者獨立不互相干擾。
  • 7. 其他補充 : OFP TOTAL FUEL 與 TAXI FUEL 僅供對照抄寫，不影響計算。DENSITY 預設 6.55 LBS/GAL，可手動調整。

💡 操作提示

  • ✔ 所有剩餘油量 / 加油後油量 / 油單公升數 / 密度 變動時，所有相關數值會立即自動更新。
  • ✔ 此頁面所有程式碼已內嵌，將本檔案儲存為 .html 檔案，即可在任何無網路環境下完整離線使用 (包含所有計算邏輯與介面)。
  • ✔ 「加完油拿到的油單資料」輸入公升(L) → 自動產生 METERED FUEL ADDED (US GAL)。
  • ✔ 「中油油單密度」欄位：輸入 KG/LITER 數值(如0.783) 後按 Enter 或離開欄位，左側 DENSITY 自動換算並重算燃油數據。
