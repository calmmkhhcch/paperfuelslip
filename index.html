📐 計算公式說明 (由上至下)

  • 1. METERED FUEL ADDED (US GAL) : 輸入「加完油拿到的油單資料 (Liters)」 → 公式 = 公升數 × 0.26417 → 四捨五入取整數，單位 US GAL。
  • 2. 剩餘油量總和 (TOTAL REMAINING) : 油箱1 + 油箱2 + CTR 剩餘油量 (LBS) 自動加總。
  • 3. 加油後油量總和 (TOTAL POST SERVICE) : 油箱1 + 油箱2 + CTR 加油後油量 (LBS) 自動加總，同時此數值即為「FINAL FUEL (LBS)」。
  • 4. *CALCULATED FUEL : 公式 = 剩餘油量總和 + ( 密度 LBS/GAL × METERED FUEL ADDED US GAL )，計算後四捨五入。
  • 5. DIFFERENCE : 公式 = CALCULATED FUEL - 加油後油量總和 (TOTAL POST SERVICE)。根據差值範圍自動標色（綠/橘/紅）。
  • 6. 中油油單密度 ➜ DENSITY 自動換算 (不四捨五入，顯示三位小數) : 若輸入「中油油單密度 (KG/LITER)」 → 乘以 8.345 → 結果直接截斷至小數點後三位(不四捨五入)，自動填入左側 DENSITY (LBS/GAL) 並觸發所有計算。
    範例：0.783 × 8.345 = 6.467375 → 顯示 6.467 。若直接修改 DENSITY 亦可，兩者獨立。
  • 7. REQUIRED (LBS) 總和計算 : 在 DISTRIBUTION 區塊，油箱 1、2、CTR 的「REQUIRED (LBS)」欄位可分別輸入需求油量，TOTAL 欄位會自動加總三個數值；若皆未輸入則顯示「需求總油量 寫在這裡」。
  • 8. 其他參考欄位 : OFP TOTAL FUEL 與 TAXI FUEL 僅供對照抄寫，不影響燃油計算邏輯。
